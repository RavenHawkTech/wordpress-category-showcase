# RavenHawk Category Showcase Plugin

This folder contains the RavenHawk Category Showcase WordPress plugin source.

## Version

2.1.0

## Basic features

- Responsive category card showcase
- Shortcode support
- Optional automatic insertion on the assigned WordPress Posts page
- Category descriptions and post counts
- Editable color and border-radius controls under RavenHawkTech → Category Showcase

## Shortcode

```text
[ravenhawk_category_showcase]
```

Example:

```text
[ravenhawk_category_showcase limit="8" show_counts="true" show_descriptions="true"]
```
